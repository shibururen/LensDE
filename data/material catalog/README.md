# Zemax material catalogs

Install the supplied AGF files under their packaged names when opening
the published ZMX prescriptions in Zemax OpticStudio.

- [CDGM.AGF](CDGM.AGF) is the same CDGM catalog used for LensDE benchmark optimization.
- [PLASTIC2026.AGF](PLASTIC2026.AGF) provides the plastic materials used by the corresponding designs.
